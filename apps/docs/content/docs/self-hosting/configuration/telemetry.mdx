---
title: Telemetry
description: Product telemetry is disabled in this fork.
---

Product telemetry, browser analytics, and session recording are removed from this fork. Legacy PostHog keys and telemetry environment variables cannot enable them. The legacy `/ingest` endpoint returns locally without forwarding requests.

Grafana and Rollbar remain the configured operational monitoring services. This setting concerns usage analytics; application integrations such as email and document signing continue to use their configured services.
